Typing Tutor for Mac
=====================

This copy is an unsigned universal app (Apple silicon and Intel).
macOS Gatekeeper will block the first open. That is normal for an app
that was not downloaded from the App Store.

Install
-------
1. Unzip the download.
2. Move "Typing Tutor.app" to the Applications folder.
3. The first time, Control-click (or right-click) the app and choose Open.
4. Choose Open again in the dialog.
5. After that, the app opens normally.

If macOS still says the app is damaged or from an unidentified developer,
open Terminal and run:

    xattr -cr "/Applications/Typing Tutor.app"

Then Control-click the app and choose Open again.

Quit
----
Close the window, or press Command-Q. The app quits so Kids Computer
can come back if it launched this app.

Progress is saved on this Mac only. The app does not use the network.
